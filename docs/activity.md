# Activity data

The profile uses versioned SVG and JSON snapshots collected from GitHub. The reporting period and snapshot date appear on each card.

- Contributions and streaks cover the displayed 365-day GitHub calendar window. Shared private contribution counts and empty or backdated commits recognized by GitHub can be included.
- Pull requests count public authored PRs across all time; stars cover owned public repositories.
- Optional commit-contribution and repository metrics require a successful GraphQL response. No lifetime commit total or productivity score is claimed.
- A failed collection retains the last successful snapshot. Counts do not establish code quality, test coverage, or production reliability.
